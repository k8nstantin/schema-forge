SchemaForge The rebuild

An open-source, intelligent, multi-engine schema design and management tool, where a coding agent and an architect work on the same live design through MCP, and nothing lands unchecked: a schema designed from scratch, reverse-engineered from a database, converted from one engine to another, its intelligence stored with it. Every database is an engine plugin; at the centre stands the database SchemaForge keeps its work in: one PostgreSQL database, schema_forge, in the PostgreSQL 18 bundled with the app, every design rows of it under its UUIDv7, holding the cortex every engine shares and each engine's own tables, each owner in its own namespace, designed before any of it is built and locked so every build falls into it.

DatabaseEvery table of the cortex, the workspace and each engine: diagrams of every foreign key, then each table with its columns, keys and file. Build SpecThe root, the rules, every task file a coding agent builds from, the decisions, and the review with every defect found. The objectivesSix, in order, each an issue with its ETA, its own branch and PR: #138, #139, #140, #141, #145, #146.
