Standards in classic modelers

Enterprise modelers enforce naming standards: Oracle SQL Developer Data Modeler (naming patterns and design rules), ER/Studio (naming standards templates). They are built for people editing by hand, not for agents. A Quest post makes the same point we do: AI that suggests a convention without enforcing it is not modelling.

Teams also write conventions as a markdown file for their agent (example): guidance the agent may follow, nothing that refuses a bad change.

MySQL to Iceberg through CDC

No tool was found that designs Iceberg tables from a MySQL schema under standards. What exists runs the pipeline and creates or evolves tables automatically: Estuary, BladePipe, Snowflake Openflow, Cloudera, Iceberg Kafka Connect on MSK, Debezium Server Iceberg, and a published MySQL-to-Iceberg type table for Firehose. None of them shows the source's inconsistencies first, or lets you decide the target design before data flows.

Where SchemaForge stands apart

  1. Your agent, any agent. It works with any coding agent that speaks MCP; Claude Code first. The MCP is the enforcer, not a convenience: every change goes through it and is checked.
  2. You direct, and can edit by hand. The user sees, points and instructs, with references to everything, or makes the change in the perspectives, under the same rules as the agent.
  3. Standards by type: type standards, naming, keys, patterns such as SCD Type 2, the Debezium pack; enforced on every operation, not suggested.
  4. Inconsistencies surfaced across the whole schema, before they become data problems.
  5. Iceberg first-class, and CDC designed: MySQL to Iceberg through Debezium, every column decided by rule, the connector's settings written to match.
  6. Local and open source (MIT or Apache-2.0).

What to watch

drawDB + MCP and Sqemo show the idea of an agent editing an ER model through MCP is already out there. SchemaForge's difference has to stay where the list above puts it: enforced standards, CDC and Iceberg, the many perspectives, and the agent as the only editor.
