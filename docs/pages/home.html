Schema Forge Draft 1

An open-source schema designer where a coding agent and an architect work on the same live design through MCP, and nothing lands unchecked. Every database is an engine plugin; at the centre stands the database Schema Forge keeps its work in: one PostgreSQL database per schema, in the PostgreSQL 18 bundled with the app, holding the cortex every engine shares and each engine's own tables, each owner in its own namespace, designed before any of it is built and locked so every build falls into it.

DatabaseEvery table of the cortex, the workspace and each engine: diagrams of every foreign key, then each table with its columns, keys and file.
